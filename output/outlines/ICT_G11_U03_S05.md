## Final outline
1. Grade 11 ICT: Understanding Data Models
2. Introduction to Data Models
3. Welcome students to the Data Models lesson
4. Define a data model as a blueprint for database design
5. Explain the purpose: organizing data and defining relationships
6. Basic Concepts in Data Modelling
7. Define Entities: people, places, or events (e.g., Student, Book)
8. Define Attributes: properties that differentiate entities (e.g., Student ID, Name)
9. Define Relationships: the association between entities (e.g., student 'borrows' book)
10. Relationship Types (Cardinality)
11. Explain One-to-one: one instance to one instance (e.g., Country to Capital City)
12. Explain One-to-many: one instance to many instances (e.g., Computer Science department to many students)
13. Explain Many-to-many: many instances to many instances (e.g., employees and projects)
14. Entity Relationship Diagrams (ERD)
15. Define ERD as a visual representation tool
16. Show visual components: Rectangles for entities, Ellipses for attributes, Lines for relationships
17. Example: Displaying a Student entity connected to a Book entity via 'borrows' relationship
18. The Relational Data Model
19. Explain the relational model: organizing data into two-dimensional tables (relations)
20. Define Rows (tuples/records) as real-world entity instances
21. Define Columns (attributes/fields) as properties
22. Implementing Relational Databases
23. Explain the role of a Relational Database Management System (RDBMS)
24. Define Primary Key: a field with unique values for each record (e.g., StudentID)
25. Define Foreign Key: a field used to link tables (e.g., StudentID in a Loan table)
26. Ethiopian Context Example: School Management
27. Display sample school tables: Student, Teacher, and Subject entities

30. Conclusion & Summary
31. Recap key concepts: Entities, Attributes, Relationships, ERD, and Tables
