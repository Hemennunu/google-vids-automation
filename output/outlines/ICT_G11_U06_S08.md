## Final outline
1. Grade 11 ICT: Conditional Statements — if, elif, else
2. Introduction
3. Conditional statements let your program make decisions based on Boolean conditions
4. The if Statement
5. if condition: — executes the block only when the condition is True
6. Indentation (4 spaces) is mandatory — it defines the code block in Python
7. Example: if score >= 50: print("You passed!")
8. The if-else Statement
9. else: — executes when the if condition is False
10. Two mutually exclusive outcomes — pass or fail, yes or no
11. Example: if score >= 50: print("Pass") else: print("Fail")
12. The if-elif-else Chain
13. elif (else-if) checks additional conditions in sequence
14. Only the first True branch executes; else catches everything else
15. Example: Grade A (≥90), B (≥75), C (≥50), Fail (<50)
16. Nested Conditionals
17. An if statement inside another if — handle complex multi-condition logic
18. Keep nesting shallow for readability; consider elif chains instead
