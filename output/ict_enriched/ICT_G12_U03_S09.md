# Unit 3 Summary



## Definition

The summary map reviews relational structure, keys, relationships, SQL command groups, integrity, and normalisation.



## Lead

Unit 3 of the Grade 12 ICT curriculum has provided a comprehensive introduction to database management systems, with a particular focus on the relational database model. This unit has equipped students with both the theoretical knowledge and the practical skills necessary to understand, design, and interact with relational databases, which form the foundation of virtually every modern information system.



## Paragraphs

The unit began with an overview of relational database management systems, introducing the core concepts of tables, records, and fields that form the structural basis of any relational database. Students learned about the critical distinction between primary keys, which uniquely identify each record within a table, and foreign keys, which establish relationships between tables. The three fundamental types of relationships were explored: one-to-one, one-to-many, and many-to-many, each of which models a different kind of real-world association between entities. The advantages of relational databases over flat-file systems were examined, with particular emphasis on reduced data redundancy, improved data integrity, and the elimination of update, insertion, and deletion anomalies through the process of normalization. The Ethiopian context was highlighted through examples drawn from the Ethiopia Commodity Exchange (ECX) database and the Ministry of Education's EMIS system, demonstrating how relational databases support critical national infrastructure.

The second major section covered database manipulation using Structured Query Language, the universal language of relational databases. Students explored the three categories of SQL commands: Data Definition Language (DDL) for creating and modifying database structures, including CREATE TABLE, ALTER TABLE, and DROP TABLE; Data Manipulation Language (DML) for managing the data within those structures, including INSERT, UPDATE, and DELETE; and Data Query Language (DQL) for retrieving data using the SELECT statement with WHERE filtering, ORDER BY sorting, and GROUP BY aggregation. Practical examples were drawn from the National Educational Assessment and Examinations Agency (NEAEA) examination results database, demonstrating how SQL queries can be used to analyse student performance across Ethiopia's diverse regions.

The worked examples section provided step-by-step solutions to realistic database design and query problems, including creating a school library database with properly defined primary keys, foreign keys, and relationships. The practical investigation section offered hands-on activities that encourage students to apply their learning through database design exercises, query writing, and normalization practice. Finally, the Cambridge AS Level extension section introduced advanced topics such as Boyce-Codd Normal Form, complex joins, subqueries, and the HAVING clause, preparing students who wish to pursue the Cambridge International AS Level examination in Information Technology.

Review Questions: 1. What are the advantages of a relational database over a flat-file system? 2. Explain the difference between a primary key and a foreign key, giving an example of each. 3. Write the SQL to create a table called 'Products' with fields ProductID (primary key), ProductName, Category, and Price. 4. What is normalization and why is it important? 5. Write a SELECT query to find the average price of products in each category, showing only categories with an average price above 100.



## Key concepts

Key Takeaways Relational databases organize data into tables connected by relationships, using primary and foreign keys to maintain referential integrity. SQL is the standard language for creating, manipulating, and querying relational databases. Normalization is a systematic process for reducing data redundancy and improving data integrity. These concepts and skills are essential for anyone pursuing further studies or careers in information technology, particularly within Ethiopia's rapidly digitizing economy.
