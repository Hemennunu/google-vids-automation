# Section 9: Cambridge AS Level Extension



## Definition

The extension visual connects structure, presentation, data, validation, and publishing in advanced web authoring.



## Lead

This section provides extension content aligned with the Cambridge International AS Level ICT 9626 syllabus, focusing on web authoring, markup languages, and website publishing as covered in the syllabus topic on web development and data exchange.



## Paragraphs

The Cambridge AS ICT 9626 syllabus requires candidates to understand the principles of web authoring using markup languages, including the differences between HTML, XHTML, and XML. Candidates must be able to explain the structure of a web page, including the document type declaration, the head and body sections, and the use of tags, elements, and attributes. A key distinction in the syllabus is between content and presentation: candidates should understand that HTML is used to structure content, while CSS is used to control presentation. The syllabus also introduces the concept of separating data from its presentation, which is where XML becomes important.

Candidates are expected to be able to create and edit simple web pages using a text editor rather than a WYSIWYG tool, demonstrating a thorough understanding of the underlying markup. They should be able to explain the purpose of the <!DOCTYPE> declaration, the importance of character encoding declarations, and the role of the meta tags in providing metadata about the page. When studying XML, candidates must understand the concept of well-formed documents, the rules for creating custom tags, and the purpose of DTDs and XML Schema for validating document structure. The syllabus also covers the use of XML in data exchange between systems, including RSS feeds, SOAP web services, and configuration files.

In terms of website publishing, the syllabus requires candidates to understand the process of transferring files to a web server using FTP, the role of web hosting, and the importance of domain names and the Domain Name System. Candidates should be able to compare different types of web hosting, including shared hosting, dedicated hosting, and cloud hosting, and recommend appropriate solutions for different scenarios. The syllabus also covers the testing and maintenance of websites, including checking for broken links, ensuring cross-browser compatibility, and implementing backup procedures. Once you have designed your website, the next step is to publish it.
Until this point, you have learnt website design. Once you have completed the

Website publishing is the process of publishing the website’s original content onto
the Internet, or specifically onto a remote server. The term 	sometimes refers to
the whole process of website design and publishing. This includes building and
uploading websites, updating the webpages, and posting content to these webpages
online. Web publishing includes personal, business, and community websites. The
content meant for web publishing can include text, videos, digital images, artwork,
and other forms of media such as music.
The most common thing about any website is that it is represented by a root di-
rectory. A root directory contains folders to organize images(.jpg,.gif), style files(.
css), and script files(.js) that are used in the website, and its index file (See Figure
4.16 below).
1. 	root: this is the top level or root folder that represents the website itself. It
contains all other files and folders of the website. For example, moe.gov.et.
2. 	index.html: contains the main homepages of the site which are written in
HTML. Web servers are by default set up to return to the index.html file if
no file name is specified. For example, if you write moe.gov.et, it returns to
moe.gov.et/index.html.
3. 	pages folder: this subfolder contains web pages of the site. For example:
about, contact us, etc. The name could be anything related to the site.
4. 	images folder: this is the subfolder that contains all the images that are
used on the site.
5. 	CSS folder: CSS code used to style the site resides in this folder. It includes,
for example setting text and background colors.

Security options
To keep your site safe and secure, a secure URL is needed. Particularly, if the site
visitors are providing their private information, HTTPS is required, not HTTP.
HTTPS (Hypertext Transfer Protocol Secure) is a protocol that is used to provide
security over the Internet. To enable HTTPS, your website needs an SSL. SSL
stands for Secure Sockets Layer which provides a secure online connection, and
your website needs an SSL Certificate. SSL is also another necessary site protocol.
It ensures your site visitor’s personal information transfers between the website
and your database are secure. SSL encrypts information (send from you/receive
from the server) to prevent others from accessing and reading it while in transit.
