# Unit 4: Web Authoring



## Definition

The visual previews how XML structures data, HTML displays content, validation checks syntax, and hosting publishes the site.



## Lead

The World Wide Web has transformed virtually every aspect of modern life, from education and commerce to communication and entertainment. For Ethiopian students, understanding how web content is created, structured, and published is not merely an academic exercise but a gateway to participating in the global digital economy. Unit 4 of the Grade 12 ICT curriculum introduces students to the fundamental concepts of web authoring, covering the markup languages that define web content, the distinction between different web technologies, and the practical steps involved in publishing a website on the internet.



## Paragraphs

The unit is organized into several key sections. It begins with an introduction to XML, the eXtensible Markup Language, which is widely used for data representation and exchange across the internet. Students will learn about XML structure, elements, attributes, the rules for creating well-formed XML documents, and the role of the XML declaration. The second section presents a detailed comparison between HTML and XML, exploring their respective strengths and weaknesses and helping students understand when each language is most appropriate. A comparison table highlights the key differences in syntax, purpose, and application of these two markup languages. The third section addresses the practical aspects of publishing a website, including domain name registration, web hosting services, file transfer methods, and basic web server configuration. Throughout the unit, examples are drawn from Ethiopian contexts, including the Ethiopian domain registry (.et), local web hosting providers, and the services offered by Ethio Telecom.

By the end of this unit, students will have a solid understanding of how web content is structured using markup languages and how websites are made available to users around the world. This knowledge forms the foundation for more advanced studies in web development, including client-side scripting with JavaScript and server-side programming with technologies such as PHP or Node.js.



## Ethiopian context

🇧🇪 Ethiopian Context Ethiopia's internet landscape has grown significantly in recent years, with increasing numbers of government services, educational institutions, and businesses establishing an online presence. The Ethiopian Telecommunications Corporation (Ethio Telecom) provides internet connectivity to millions of subscribers, and the Ethiopian Internet Observatory (.et domain registry) manages the country's top-level domain. Organizations such as the Ethiopian Information Network Security Agency (INSA) oversee the security and governance of Ethiopia's cyberspace. Understanding web authoring and publishing is therefore essential for students who wish to contribute to Ethiopia's growing digital ecosystem, whether by creating educational content, building e-commerce platforms, or developing e-government services.



## Key concepts

Key Concept Web authoring encompasses the skills and technologies needed to create, structure, and publish content on the World Wide Web. XML provides a flexible framework for data representation, while HTML remains the standard for web page display. Understanding both languages, and knowing how to publish content online, are fundamental skills for any aspiring web professional.

A markup language is a type of computer language that uses tags such as
“<” and “>” to define elements in a document.
XML 	stands for Extensible Markup Language which is a way to apply
structure to a web page. XML provides a standard open format and mechanisms
for structuring a document so that it can be exchanged and manipulated.
An XML document contains the following: XML declaration, Document
Type Declaration (DTD), Internal DTD subset, XML information set /
Content, Root element, Tags, Data, Attributes, and Comments.
Points to remember while you work on XML:
• 	You should have one root in an XML document.
• 	XML elements are case-sensitive.
• 	XML should not overlap or all elements must properly be nested within
each other.
• 	XML attribute values must always be in quotation marks.
• 	Comments in XML follow the HTML comment structure.
• 	XML does not truncate multiple whitespaces.
• 	Special characters need entity references, otherwise, they create errors.
HTML and XML are two different markup languages. HTML is the markup
language to design and create web content, whereas XML is a markup
language designed to store data. It is popularly used for the transfer of data.
However, the two complement each other.
Entity References: This refers to characters that have 	special meaning in
XML. There are 5 pre-defined entity references in XML, such as &lt; (<),
&gt; (>), &amp; (&), &apos; (‘), and &quot; (“).
You can open and edit XML with any text editor, and view it with any web
browser, or use a website that lets you view, edit, and even convert it to other
formats.
In DTD the !DOCTYPE - defines the root element of the document.
