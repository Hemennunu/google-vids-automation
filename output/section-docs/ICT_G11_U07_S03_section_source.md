# ICT_G11_U07_S03 — PART C: EXTENDED RESPONSE QUESTIONS

Grade 11 ICT (Ethiopian curriculum). Textbook sub-chapter: none matched.

## MUST-COVER CHECKLIST (teach every item)
- s Commercial Bank
- Decision Support System

## LMS LESSON (authoritative)
LEAD

Instructions: Answer ALL questions. Write in full sentences with clear explanations. Each question carries 10 marks.

PARAGRAPHS

Question C1 — Information Systems and Emerging Technologies (10 marks)

Ethiopia's Commercial Bank (CBE) has implemented a comprehensive digital banking system incorporating AI, cloud computing, and IoT. (a) Describe how a Decision Support System (DSS) could assist CBE's senior management in making strategic decisions. (3 marks) (b) Explain how cloud computing benefits CBE's digital operations, including at least TWO specific advantages. (4 marks) (c) Discuss ONE ethical concern associated with CBE's use of AI in approving or rejecting loan applications, and suggest how this concern could be addressed. (3 marks)

Question C2 — Database Design and Development (10 marks)

Design a relational database for the Addis Ababa City Administration to manage its public library system. (a) Identify THREE entities needed for this database and list at least three attributes for each entity. (3 marks) (b) Draw or describe an Entity-Relationship (ER) diagram showing the relationships between your entities, clearly indicating primary keys and foreign keys. (4 marks) (c) Write an SQL query to retrieve the titles of all books currently borrowed by a member with MemberID = 1042. (3 marks)

Question C3 — Web Development and Programming (10 marks)

You have been asked to create a website for a local Ethiopian NGO that promotes digital literacy in rural communities. (a) Describe the key principles of good website design that you would apply, giving one specific example for each principle. (4 marks) (b) Write the HTML and CSS code for a webpage that displays the NGO's name as a styled heading, a brief description paragraph, and a navigation menu with three links. (4 marks) (c) Write a Python function that calculates and returns the percentage of a community that has achieved digital literacy, given the total population and the number of literate individuals. Include a test with sample data. (2 marks)
