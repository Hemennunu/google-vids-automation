Grade 11 ICT (Ethiopian curriculum). Textbook sub-chapter: none matched.

Instructions: Answer ALL questions. Show your reasoning clearly. Each question carries 5 marks.

PARAGRAPHS

Question B1 — Unit 1: Information Systems (5 marks)

A school in Addis Ababa wants to install a student record management system. (a) Distinguish between data and information, giving one example from this school context. (2 marks) (b) Identify and describe ONE type of information system that would be most suitable for managing student records, explaining why it is appropriate. (3 marks)

Question B2 — Unit 2: Emerging Technologies (5 marks)

Ethio Telecom has introduced an AI-powered customer service chatbot. (a) Define Artificial Intelligence. (1 mark) (b) Describe TWO benefits and ONE potential risk of using AI chatbots in Ethiopian telecommunications. (4 marks)

Question B3 — Unit 3: Database Management (5 marks)

A hospital database stores patient information. The PATIENTS table has fields: PatientID, Name, Age, WardID. The WARDS table has fields: WardID, WardName, Capacity. (a) Identify the primary key in the PATIENTS table and explain its purpose. (2 marks) (b) Write a SQL query to retrieve the Name and Age of all patients older than 50. (3 marks)

Question B4 — Unit 4: Web Development (5 marks)

Write the HTML code to create a webpage with: (a) A page title of "MyMarian Platform" visible on the browser tab. (1 mark) (b) A first-level heading reading "Welcome to Grade 11 ICT". (1 mark) (c) An unordered list with three items: "Information Systems", "Web Development", "Programming". (3 marks)

Question B5 — Unit 5: Hardware Troubleshooting (5 marks)

A student's computer starts but the monitor shows no image. (a) List THREE possible causes of this problem. (3 marks) (b) Describe the steps you would take to diagnose and resolve the issue. (2 marks)

Question B6 — Unit 6: Programming (5 marks)

Write a Python program that: (a) Asks the user to enter two numbers. (1 mark) (b) Calculates and prints their sum, difference, and product. (3 marks) (c) Uses a function called calculate() to perform the calculations. (1 mark)
