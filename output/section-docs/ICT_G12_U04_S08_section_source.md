## LMS LESSON (authoritative)
LEAD

This practical investigation will guide you through creating a simple XML document, validating its structure, and preparing it for publication. The activity can be completed using a text editor and an XML validator, all of which are freely available online.

PARAGRAPHS

✅ Check Your Understanding: After completing this investigation, you should be able to create a well-formed XML document from scratch, validate it using online tools, write a basic DTD to define document structure, and explain how XML can be used for data representation in Ethiopian organisations.
