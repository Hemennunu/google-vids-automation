Lesson content (authoritative — stay accurate and do not add facts beyond it):
Structured Query Language (SQL) is the standard programming language used for managing and manipulating relational databases. Developed at IBM in the 1970s and later standardized by the American National Standards Institute (ANSI) and the International Organization for Standardization (ISO), SQL has become the universal language for interacting with relational database systems. SQL commands are categorized into several groups based on their function: Data Definition Language (DDL) for defining database structures, Data Manipulation Language (DML) for managing data within those structures, and Data Query Language (DQL) for retrieving data. Mastery of SQL is an essential skill for anyone working with databases, from database administrators and developers to data analysts and researchers.

DDL commands are used to define, modify, and remove database structures such as tables, indexes, and schemas. The three primary DDL commands are CREATE, ALTER, and DROP. The CREATE statement is used to create new database objects.

DML commands are used to manage the data stored within database tables. The three primary DML commands are INSERT, UPDATE, and DELETE. The INSERT statement adds new rows of data to a table. When a new student's examination results are received by the National Educational Assessment and Examinations Agency (NEAEA), an INSERT statement would be executed to add that student's record to the database.

The SELECT statement is the primary DQL command, used to retrieve data from one or more tables. SELECT queries can range from simple retrievals of all columns and rows to complex queries involving multiple tables, filtering conditions, sorting, and grouping. The basic syntax is SELECT column1, column2 FROM table WHERE condition.
