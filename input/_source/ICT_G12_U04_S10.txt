# Section 10: Unit Summary



## Definition

The summary map reviews XML syntax, HTML and XHTML comparison, validation, hosting, domains, and website publishing.



## Lead

This unit has explored the fundamental concepts of web authoring, focusing on markup languages, their structures, and the process of making web content available on the internet. By the end of this unit, you should have a solid understanding of XML, the differences between HTML and XHTML, and the steps required to publish a website.



## Paragraphs

The first part of the unit introduced XML as a powerful markup language designed for storing and transporting structured data. Unlike HTML, which uses a fixed set of tags for displaying content in a browser, XML allows you to create custom tags that describe the meaning of your data. We learned that XML documents must be well-formed, meaning they must follow strict syntax rules: a single root element, properly closed and nested tags, and quoted attribute values. The XML declaration specifies the version and encoding, and validation tools such as DTDs and XML Schema ensure that documents conform to defined structures. XML plays a critical role in data exchange between different systems, making it essential for modern ICT applications such as e-government data sharing, financial transactions between banks, and educational record transfers between institutions.

The second part of the unit examined the relationship between HTML, XHTML, and XML. HTML remains the standard for presenting content in web browsers, with its predefined tags for headings, paragraphs, links, and images. XHTML serves as a bridge, combining the strict syntax rules of XML with the familiar tag set of HTML. We discussed the advantages and disadvantages of each language: HTML is forgiving and easy to learn but lacks data description capabilities; XML is strict and extensible but more verbose; and XHTML offers the rigour of XML while remaining compatible with web browsers. Understanding when to use each language is a key skill for web developers, and Ethiopian websites using the .et domain provide real-world examples of these technologies in practice.

The final part of the unit covered the practical aspects of website publishing. We explored how domain names are registered through registrars such as EthioTelecom for .et domains, how web hosting services provide server space for website files, and how FTP enables the transfer of files from a local computer to a hosting server. The publishing process requires careful planning, from choosing the right hosting type to ensuring that files are correctly organised and uploaded. As Ethiopia's digital presence continues to expand, the skills you have gained in this unit will enable you to contribute to building and maintaining websites for schools, businesses, and community organisations.

✅ Unit Summary: This unit has equipped you with knowledge of XML for data representation, the distinctions between HTML, XHTML, and XML, and the complete process of publishing a website from domain registration to FTP upload. These skills form the foundation of professional web authoring and are increasingly valuable as Ethiopia's digital economy grows.
