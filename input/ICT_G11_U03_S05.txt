Lesson content (authoritative — stay accurate and do not add facts beyond it):
This unit covers Database Management as part of the Grade 11 ICT curriculum, aligned with the Ethiopian MoE 2023 standard textbook.

A data model is a conceptual representation of the data structures required by a database, defining what data is stored, how it is organised, and the relationships among different data elements. Data models serve as blueprints for database design, providing a clear and precise description of the data requirements of an organisation before any actual database implementation begins.

An Entity-Relationship Diagram (ERD) is a graphical tool used to represent a data model visually. In an ERD, entities are real-world objects or concepts about which data must be stored, such as a Student, Course, or Department. Each entity is represented as a rectangle in the diagram. Attributes describe properties of entities, such as a student's name, ID number, date of birth, and address.

Each entity in an ERD must have a primary key, an attribute or combination of attributes that uniquely identifies each record in the entity. For the Student entity, StudentID serves as the primary key because no two students share the same ID number. Foreign keys are attributes in one entity that reference the primary key of another entity, establishing relationships between them.
