Key concepts:
- Key Takeaways Relational databases organize data into tables connected by relationships, using primary and foreign keys to maintain referential integrity. SQL is the standard language for creating, manipulating, and querying relational databases. Normalization is a systematic process for reducing data redundancy and improving data integrity. Lesson content (authoritative — stay accurate and do not add facts beyond it):
Unit 3 of the Grade 12 ICT curriculum has provided a comprehensive introduction to database management systems, with a particular focus on the relational database model. This unit has equipped students with both the theoretical knowledge and the practical skills necessary to understand, design, and interact with relational databases, which form the foundation of virtually every modern information system.

The unit began with an overview of relational database management systems, introducing the core concepts of tables, records, and fields that form the structural basis of any relational database. Students learned about the critical distinction between primary keys, which uniquely identify each record within a table, and foreign keys, which establish relationships between tables.

The second major section covered database manipulation using Structured Query Language, the universal language of relational databases.

The worked examples section provided step-by-step solutions to realistic database design and query problems, including creating a school library database with properly defined primary keys, foreign keys, and relationships. The practical investigation section offered hands-on activities that encourage students to apply their learning through database design exercises, query writing, and normalization practice.
