Cambridge International AS Level Information Technology (9626): This section extends the Ethiopian Grade 12 curriculum with additional depth aligned to the Cambridge AS Level syllabus, particularly focusing on advanced database concepts and SQL techniques that are assessed in the Cambridge examinations.

The Cambridge AS Level Information Technology syllabus requires students to demonstrate a deeper understanding of database concepts than the standard Grade 12 curriculum.

While the Ethiopian curriculum covers normalization through the first three normal forms, the Cambridge syllabus may also introduce the concept of Boyce-Codd Normal Form (BCNF), which is a stricter version of 3NF. A table is in BCNF if, for every functional dependency X → Y, X is a candidate key. In practice, any table that is in 3NF and has no overlapping candidate keys is also in BCNF.

Cambridge AS Level candidates are expected to write SQL queries that go beyond basic SELECT statements. They must be proficient in multi-table joins using both INNER JOIN and LEFT JOIN syntax, correlated and non-correlated subqueries, the use of aliases to improve query readability, and the application of aggregate functions combined with the HAVING clause for filtering grouped data.

In Cambridge AS Level examination papers on database topics, students are frequently asked to interpret given table structures and write SQL queries to answer specific questions. The examiners expect precise syntax: keywords such as SELECT, FROM, WHERE, GROUP BY, HAVING, ORDER BY must appear in the correct sequence.

Cambridge Practice Question: A school database contains two tables: Student (StudentID, FirstName, LastName, YearGroup) and SubjectResult (ResultID, StudentID, Subject, Score).

Check Your Understanding: Why does the HAVING clause exist separately from the WHERE clause? What is the fundamental difference in when these two clauses are evaluated during query execution? Explain using an example where using WHERE instead of HAVING would produce incorrect results.
